# AGENTS.md — TeachMyPC

## Project

TeachMyPC is a macOS-first desktop automation application built with Angular, Tauri 2, Rust, and Ollama (Gemma 3 4B).

Users describe file automation rules in natural language. AI produces structured proposals, while deterministic Rust code validates and executes approved operations.

## Engineering principles

- Prioritize a working vertical slice over feature breadth.
- Use simple, maintainable architecture. Avoid unnecessary abstractions.
- Follow Angular standalone component and signals best practices.
- Keep Angular components focused on presentation and interaction.
- Keep filesystem operations in Rust, never in frontend code.
- Use strict TypeScript and typed Tauri IPC contracts.
- Avoid `any`, unsafe type assertions, and silent error handling.
- Never execute shell commands generated by AI.
- Never allow AI-generated paths to authorize filesystem access.
- Require explicit approval before enabling rules.
- Reject unsupported or ambiguous instructions.
- Never overwrite or delete user files silently.
- Use temporary directories for filesystem tests.
- Include meaningful unit tests for domain logic and edge cases.
- Prefer existing project dependencies before adding new packages.
- Do not add authentication, analytics, telemetry, payments, or cloud services.
- Do not refactor unrelated code.
- Keep documentation concise and accurate.

## Workflow

1. Inspect only relevant files.
2. State a short implementation plan.
3. Implement the requested scope.
4. Run targeted checks and tests.
5. Report files changed, tests run, and remaining issues.

## Token efficiency

- Do not repeatedly summarize the entire repository.
- Avoid unnecessary documentation or explanatory comments.
- Do not print entire files unless explicitly requested.
- Report only important implementation decisions.
- Ask questions only when blocked by a critical ambiguity.
- Never claim tests passed unless they were actually executed.

## MVP scope

- Natural-language rule creation.
- Gemma 3 via local Ollama.
- Strict schema validation.
- Rule preview and approval.
- User-authorized folder selection.
- File-created trigger.
- Rename, move, and copy actions.
- Local persistence and activity history.
- Dry-run preview.

Anything else requires explicit approval.
